# Requisito original

O sistema deve carregar e exibir as publicações disponíveis no feed da aplicação para usuários autenticados, apresentando obrigatoriamente o autor e o conteúdo de cada postagem, além de exibir a imagem associada, quando houver.

# História de usuário

Como usuário autenticado no sistema,
quero visualizar as publicações de outros usuários no feed da aplicação,
para interagir com outros usuários.

# Critérios de aceitação

1. Dado que estou autenticado no sistema,
   quando acesso a página do feed da aplicação,
   então o sistema carrega e exibe as publicações disponíveis de outros usuários, apresentando o autor, o conteúdo textual e a imagem associada (caso exista).
