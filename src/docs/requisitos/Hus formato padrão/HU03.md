# Requisito original

O sistema deve permitir que usuários autenticados criem e compartilhem publicações no feed da aplicação contendo texto obrigatório e, opcionalmente, uma imagem anexada, impedindo o envio caso o conteúdo de texto esteja vazio.

# História de usuário

Como usuário autenticado no sistema,
quero poder publicar texto e/ou imagens no feed da aplicação,
para compartilhar informações e interagir com outros usuários.

# Critérios de aceitação

1. Dado que estou autenticado no sistema,
   quando preencho os campos de texto e imagem e clico no botão de publicar,
   então o sistema registra a publicação e a exibe no feed.

2. Dado que estou autenticado no sistema,
   quando tento publicar sem preencher o conteúdo de texto,
   então o sistema impede a publicação e exibe uma mensagem de validação.

3. Dado que estou autenticado no sistema,
   quando preencho apenas o conteúdo textual da publicação e clico no botão de publicar,
   então o sistema registra a publicação e a exibe no feed da aplicação sem imagem associada.
