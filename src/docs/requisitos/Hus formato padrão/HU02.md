# Requisito original

O sistema deve permitir a autenticação de usuários por meio de nome de usuário e senha, redirecionando para a página principal e liberando o acesso às funcionalidades exclusivas do sistema conforme seu nível de permissão.

# História de usuário

Como visitante do site,
quero acessar minha conta de usuário,
para acessar as funcionalidades exclusivas como usuário do sistema.

# Critérios de aceitação

1. Dado que sou um visitante do site,
   quando preencho o formulário de login com um nome de usuário e uma senha e clico no botão de Login,
   então o sistema valida as credenciais, autentica o usuário, redireciona para a página principal e libera o acesso aos recursos do sistema de acordo com seu grau de autorização.
