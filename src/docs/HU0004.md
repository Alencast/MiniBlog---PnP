## 1. Especificação da História de Usuário

- **Como:** Usuário autenticado no sistema
- **Quero:** Poder comentar nas publicações do feed da aplicação
- **Para:** Compartilhar informações e interagir com outros usuários

<br>

## 2. Cenários

### **2.1. Cria Comentário**

- **DADO** Que estou autenticado no sistema
- **QUANDO** Preencho o campo de comentário de uma publicação
- **E** Clico no botão de comentar
- **ENTÃO** O sistema registra o comentário e o mostra abaixo da publicação

### **2.2. Cria Comentário sem Conteúdo**

- **DADO** Que estou autenticado no sistema
- **QUANDO** Tento comentar algo sem passar nenhum conteúdo
- **ENTÃO** O sistema deve impedir e mostrar uma mensagem de validação

### 2.3. Cria Comentário acima do limite permitido

- **DADO** que estou autenticado no sistema
- **QUANDO** tento enviar um comentário com mais de 280 caracteres
- **ENTÃO** o sistema deve impedir o envio e exibir mensagem de validação

<br>

## 3. Critérios de Aceitação:

- [x] **3.1.** Após o comentário ser enviado com sucesso, ele deve ser exibido abaixo da publicação correspondente sem necessidade de recarregar a página
- [x] **3.2.** O sistema deve impedir a criação de comentários sem texto
- [x] **3.3.** O comentário deve possuir no máximo 280 caracteres
- [x] **3.4.** Cada comentário deve estar associado a exatamente uma publicação
- [x] **3.5.** Uma publicação pode possuir vários comentários
- [x] **3.6.** O comentário deve armazenar o autor

<br>
