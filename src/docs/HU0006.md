## 1. Especificação da História de Usuário

- **Como:** Usuário autenticado no sistema
- **Quero:** Comentar publicações de outros usuários
- **Para:** Interagir com outros usuários

<br>

## 2. Cenários

### **2.1. Criar comentário válido**

- **DADO** que estou autenticado no sistema
- **QUANDO** preencho o campo de comentário de uma publicação
- **E** clico no botão de comentar
- **ENTÃO** o sistema registra o comentário e o exibe na publicação

### **2.2. Criar comentário sem conteúdo**

- **DADO** que estou autenticado no sistema
- **QUANDO** tento enviar um comentário sem informar conteúdo
- **ENTÃO** o sistema deve impedir o envio e exibir uma mensagem de validação

<br>

## 3. Critérios de Aceitação:

- [x] **3.2.** O comentário deve ser exibido abaixo da publicação após o envio.
- [x] **3.3.** O sistema não deve permitir comentários vazios.
- [x] **3.4.** O sistema não deve permitir comentários com mais de 280 caracteres.
- [x] **3.5.** Cada comentário deve estar associado ao usuário que o criou.

<br>

## 4. Especificações Técnicas:

### 4.1. Campos do formulário de comentário:

| Campos   | Descrição           | Tipo de Campo | Tipo do Dado | Tamanho | Máscara | Editável | Obrigatório | Regras                                                     |
| -------- | ------------------- | ------------- | ------------ | ------- | ------- | -------- | ----------- | ---------------------------------------------------------- |
| Conteúdo | Texto do comentário | Texto         | Alfanumérico | 280     | N/A     | S        | S           | Não pode ser vazio e deve possuir no máximo 280 caracteres |
