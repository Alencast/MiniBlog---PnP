## 1. Especificação da História de Usuário

- **Como:** Usuário autenticado no sistema
- **Quero:** Poder publicar texto e/ou imagens no feed da aplicação
- **Para:** Compartilhar informações e ainteragir com outros usuários

<br>

## 2. Cenários

### **2.1. Cria Publicação**

- **DADO** Que estou autenticado no sistema
- **QUANDO** Preencho os campos de texto e imagem
- **E** Clico no botão de publicar
- **ENTÃO** O sistema registra a publicação e mostra no feed

### **2.2. Cria Publicação sem Conteúdo**

- **DADO** Que estou autenticado no sistema
- **QUANDO** Tento publicar algo sem passar nenhum conteúdo
- **ENTÃO** O sistema deve impedir a publicação e mostrar uma mensagem de validação

### **2.3. Cria Publicação sem Imagem**

- **DADO** Que estou autenticado no sistema
- **QUANDO** Preencho apenas o conteúdo textual da publicação
- **ENTÃO** O sistema registra a publicação e a exibe no feed da aplicação sem imagem associada

<br>

## 3. Critérios de Aceitação:

- [x] **3.1.** Após a publicação a mensagem deve ser mostrada no feed.
- [x] **3.2.** O sistema deve impedir a criação de publicações sem texto.
- [x] **3.3.** AO usuário autenticado deve conseguir anexar uma imagem à publicação.

<br>

## 4. Especificações Técnicas:

### 4.1. Campos do Formulário de Publicação:

| Campos   | Descrição                   | Tipo de Campo     | Tipo do Dado | Tamanho | Máscara | Editável | Obrigatório | Regras             |
| -------- | --------------------------- | ----------------- | ------------ | ------- | ------- | -------- | ----------- | ------------------ |
| Conteúdo | Texto da publicação         | Texto             | Alfanumérico | N/A     | N/A     | S        | S           | Não pode ser vazio |
| Imagem   | Imagem anexada à publicação | Upload de Arquivo | Alfanumérico | N/A     | N/A     | S        | S           |                    |
