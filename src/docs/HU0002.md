## 1. Especificação da História de Usuário

- **Como:** Visitante do site
- **Quero:** Acessar sua conta de usuário
- **Para:** Acessar as funcionalidades exclusivas como usuário do sistema

<br>

## 2. Cenários

### **2.1. Login de Usuário**

- **DADO** Que sou um visitante do site
- **QUANDO** Preencho o formulário de login com um nome e uma senha.
- **E** Clico no botão de Login
- **ENTÃO** Então o sistema valida as credenciais, autentica o usuário e o redireciona para a página principal

<br>

## 3. Critérios de Aceitação:

- [x] **3.1.** O usuário deve ser redirecionado para a página principal da aplicação e deve poder acessar sua conta e os recursos do sistema de acordo com seu grau de autorização.

<br>

## 4. Especificações Técnicas:

### 4.1. Campos do Formulário de Login de Usuário:

| Campos  | Descrição                              | Tipo de Campo | Tipo do Dado | Tamanho | Máscara | Editável | Obrigatório | Regras |

| Usuário | Nome do usuário usado para fazer login | Texto         | Alfanumérico | N/A     | N/A     | S        | S           |        |
