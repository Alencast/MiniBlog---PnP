## 1. Especificação da História de Usuário

- **Como:** Usuário autenticado no sistema
- **Quero:** Visualizar publicação de outros usuários no feed da aplicação
- **Para:** Interagir com outros usuários

<br>

## 2. Cenários

### **2.1. Visualizar postagens**

- **DADO** Que estou autenticado no sistema
- **QUANDO** Acessar o feed
- **ENTÃO** O sistema mostra as publicações de outros usuários

<br>

## 3. Critérios de Aceitação:

- [x] **3.1.** O sistema deve exibir as publicações disponíveis no feed.
- [x] **3.2.** Cada publicação deve apresentar autor e conteúdo.
- [x] **3.3.** As publicações devem ser carregadas corretamente ao acessar o feed.

<br>

## 4. Especificações Técnicas:

### 4.1. Campos exibidos na publicação:

| Campos    | Descrição                               | Tipo de Campo | Tipo do Dado | Tamanho | Máscara | Editável | Obrigatório | Regras             |
| --------- | --------------------------------------- | ------------- | ------------ | ------- | ------- | -------- | ----------- | ------------------ |
| Autor     | Nome do usuário que realizou a postagem | Texto         | Alfanumérico | N/A     | N/A     | N        | S           | Não pode ser vazio |
| Conteúdo  | Texto da publicação                     | Texto         | Alfanumérico | N/A     | N/A     | N        | S           |                    |
| Imagem    | Imagem associada                        | File          |              |         |         | N        | N           |                    |
| Descrição | Conteúdo textual da publicação          | Texto         |              |         |         | N        | S           | Não pode ser vazio |
