# Glossário

## Termos

| Termo | Definição |
|---|---|
| **Usuário** | Pessoa que utiliza o sistema para visualizar, publicar e interagir com conteúdos. |
| **Post** | Publicação criada por um usuário, podendo conter texto e imagem. |
| **Comentário** | Conteúdo textual publicado por um usuário em resposta a um post. |
| **Imagem** | Arquivo visual associado a uma publicação. |
| **Publicação** | Conteúdo disponibilizado no miniblog por um usuário. |
| **Feed** | Área destinada a exibição das publicações disponíveis no sistema. |
| **Autenticação** | Processo de verificação da identidade de um usuário para acesso ao sistema. |
| **Cadastro** | Processo de criação de uma conta de usuário no sistema. |
| **Login** | Processo onde o usuário acessa sua conta de perfil no sistema. |
| **Perfil** | Área que reúne as informações e publicações associadas a um usuário. |

## Termos Técnicos

| Termo | Definição |
|---|---|
| **Frontend** | Parte do sistema responsável pela interface e interação com o usuário. |
| **Backend** | Parte do sistema responsável pelo processamento das regras de negócio e das requisições. |
| **API** | Interface que permite a comunicação entre diferentes componentes ou sistemas. Como a comunicação feita entre o frontend e o backend do sistema. |
| **Banco de Dados** | Estrutura responsável pelo armazenamento e gerenciamento dos dados do sistema. |
| **CRUD** | Conjunto de operações de criação, consulta, atualização e exclusão de dados. |
| **Requisição** | Solicitação enviada de um componente do sistema para outro, geralmente para obter ou modificar dados. |
